# 💫 About Me

I'm a passionate **DevOps / DevSecOps Engineer with 6.3 years of overall IT experience, including 5 years of hands-on DevOps experience**, specializing in cloud infrastructure automation, CI/CD pipeline engineering, containerization, and secure application deployments.

I have experience designing, implementing, and managing scalable AWS infrastructure using Infrastructure as Code (IaC), automating application deployments, and integrating security practices into CI/CD workflows.

### 🚀 What I Do

- ☁️ Design and manage AWS cloud infrastructure.
- 🏗️ Automate infrastructure provisioning using Terraform and Ansible.
- ⚙️ Build and maintain CI/CD pipelines using Jenkins and GitHub Actions.
- 🐳 Build and manage Docker containers.
- ☸️ Deploy and manage containerized applications using Kubernetes and Amazon EKS.
- 🔄 Implement GitOps workflows using Argo CD and Helm.
- 🔐 Integrate security scanning using Trivy and SonarQube.
